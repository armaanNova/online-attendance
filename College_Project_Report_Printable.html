Project Abstract

The Online Smart Face Recognition Attendance Management System is a computerized, contactless biometric web application engineered to completely eliminate proxy attendance (buddy punching) in college environments. The system utilizes modern Computer Vision techniques powered by OpenCV (Haar Cascade detection, CLAHE lighting equalization, and Histogram of Oriented Gradients feature extraction) combined with a high-throughput Python FastAPI backend and MySQL relational database.

Algorithms & Formulations

1. Viola-Jones Face Detection (Haar Cascades)

The system detects human faces using OpenCV's pre-trained Haar Cascades. Features are computed in constant time using an Integral Image, and weak classifiers selected via AdaBoost quickly discard background regions.

2. Lighting Normalization (CLAHE)

To handle variable webcam lighting, Contrast Limited Adaptive Histogram Equalization divides the face into \(8 \times 8\) tiles and clips local histograms at \(2.5\) before redistributing contrast, preventing over-amplified noise.

3. Biometric Feature Extraction (HOG Descriptor)

The cropped face is resized to \(128 \times 128\) pixels. Spatial gradients (\(G_x, G_y\)) and orientation bins generate a 1,764-dimensional structural vector combined with a 256-dimensional spatial intensity grid, yielding a 2,020-dimensional vector normalized via L2 norm: 

norm = sqrt(sum(v_i^2))
v_normalized = v / norm

4. Cosine Similarity Matching

Given query vector \(\mathbf{A}\) and stored database vector \(\mathbf{B}\), the metric is evaluated as: 

Cosine Similarity(A, B) = dot_product(A, B) / (||A|| * ||B||) = dot_product(A, B)
  • Similarity ≥ 0.70: Face Verified • Status: Present
  • Similarity < 0.70: Face Rejected • "Face Not Recognized. Please Register First."
  • Second scan on same date: "Attendance Already Marked Today."

import numpy as np
DEFAULT_THRESHOLD = 0.70
DUPLICATE_THRESHOLD = 0.86

def calculate_cosine_similarity(vec_a: np.ndarray, vec_b: np.ndarray) -> float:
    norm_a = np.linalg.norm(vec_a)
    norm_b = np.linalg.norm(vec_b)
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return float(np.dot(vec_a, vec_b) / (norm_a * norm_b))

def find_matching_student(query_embedding, registered_database, threshold=DEFAULT_THRESHOLD):
    if not registered_database:
        return None, 0.0, False
    best_match_id = None
    best_similarity = -1.0
    for record in registered_database:
        similarity = calculate_cosine_similarity(query_embedding, record["embedding"])
        if similarity > best_similarity:
            best_similarity = similarity
            best_match_id = record["student_id"]
    is_match = (best_similarity >= threshold) and (best_match_id is not None)
    return best_match_id, best_similarity, is_match

@router.post("/mark", response_model=schemas.AttendanceMarkResponse)
def mark_face_attendance(req: schemas.AttendanceMarkRequest, db: Session = Depends(get_db)):
    frame = decode_base64_image(req.image_base64)
    face_crop, bbox, conf = detect_face(frame, min_size=60)
    if face_crop is None:
        return schemas.AttendanceMarkResponse(success=False, status_code="NO_FACE_DETECTED", message="No face detected.")

    query_embedding = extract_embedding(face_crop)
    registered_records = db.query(models.FaceEmbedding).all()
    registered_db = [{"student_id": r.student_id, "embedding": deserialize_embedding(r.embedding_vector)} for r in registered_records]

    matched_id, score, is_match = find_matching_student(query_embedding, registered_db)
    if not is_match or matched_id is None:
        return schemas.AttendanceMarkResponse(success=False, status_code="UNRECOGNIZED", message="Face Not Recognized. Please Register First.")

    student = db.query(models.Student).filter(models.Student.student_id == matched_id).first()
    today = datetime.date.today()

    # Duplicate Attendance Guard
    existing = db.query(models.Attendance).filter(models.Attendance.student_id == student.student_id, models.Attendance.date == today).first()
    if existing:
        return schemas.AttendanceMarkResponse(success=False, status_code="ALREADY_MARKED", message="Attendance Already Marked Today.", student_id=student.student_id, full_name=student.full_name, roll_number=student.roll_number, time=existing.time.strftime("%I:%M:%S %p"))

    # Log New Attendance
    new_att = models.Attendance(student_id=student.student_id, date=today, time=datetime.datetime.now().time(), status="Present", confidence_score=float(score))
    db.add(new_att)
    db.commit()
    return schemas.AttendanceMarkResponse(success=True, status_code="SUCCESS", message="Attendance Marked Successfully!", student_id=student.student_id, full_name=student.full_name, roll_number=student.roll_number, date=str(today), time=new_att.time.strftime("%I:%M:%S %p"))

Viva-Voce Questions & Model Answers

Q1: Why choose FastAPI instead of Django or Flask?
Answer: FastAPI is asynchronous (ASGI based on Starlette and Pydantic), executing up to 300% faster than Flask. It natively handles image buffer processing and automatically generates interactive OpenAPI/Swagger docs.

Q2: Why use Cosine Similarity instead of Euclidean Distance?
Answer: Euclidean distance is sensitive to vector magnitude variations caused by ambient lighting changes. Cosine similarity calculates the cosine of the angle between normalized unit vectors, making it scale-invariant, faster ($O(N)$ dot product), and bounded between $-1$ and $+1$.

Q3: How is duplicate attendance prevented?
Answer: Enforced via a MySQL composite unique constraint UNIQUE (student_id, date) and backend logic checking if an entry exists for the current date before inserting.
